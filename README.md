Cardio Care: Heart Disease Risk Predictor

Cardio Care is a machine learning-based health-tech application designed to assess and predict the risk of heart disease based on clinical patient metrics.

The core predictive engine was trained and evaluated using multiple classification architectures, primarily focusing on Decision Trees and K-Nearest Neighbors (KNN), to ensure optimal accuracy. 
The project bridges backend data science with frontend accessibility, featuring a custom HTML web interface and a fully interactive deployment via Streamlit. 
It allows users to input their medical data and receive instant, real-time risk assessments.

Tech Stack:
Language: Python
Machine Learning: Scikit-Learn, Pandas, NumPy
Frontend/Deployment: Streamlit, HTML
Models Used: Decision Tree Classifier, K-Nearest Neighbors (KNN)
